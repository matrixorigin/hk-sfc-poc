跟现有 UI 的关系：
  • 颜色 / 字体 / 圆角 / 边框跟现有 chat-section 完全一致（蓝主色、系统字体、6-10px 圆角、淡灰边）
  • 所有控件都在水平 selector 里横排，跟现有 chart-field-selector 同一种语言，只是项变多
  • 新增控件：per-metric 主/副轴切换（L|R 角标点一下切换）、排序+TopN、数据标签开关、4 种新图表 chip
  • 不兼容的图表（热力 / 蜡烛）灰掉 + 角标 !，hover 看原因
  • 变体 shelf（热力 / 蜡烛）字段角色不同但视觉语言完全一致
