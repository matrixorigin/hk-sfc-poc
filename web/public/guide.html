香港市场数据探索

AI 驱动的金融数据查询、分析与可视化工具

1功能概览

系统面向香港证券市场数据分析场景，支持用自然语言查询恒生指数、个股行情、市值与行业分类、新闻公告、财务报表和 CCASS 持仓。系统自动生成 SQL、执行查询，并以表格、图表和文字说明呈现结果。

管理员和普通用户共用登录入口。普通用户可以使用全部分析功能；用户管理仅管理员可见、可操作。

2核心功能

💬 自然语言查询
直接描述分析目标，支持流式回答、追问和上下文会话。
🗂️ 数据源选择
按问题选择系统数据表或个人上传的数据表，缩小分析范围。
📊 表格与图表
查看查询结果、分页数据，并切换折线、柱状、饼图等展示方式。
🧮 计算链路
查看关键字段口径、SQL 与 Python 脚本，并下载一键复现包。
📁 自定义数据表
上传 CSV 或 Excel，预览字段、确认类型和备注后创建个人数据表。
🧠 知识库
维护业务逻辑、术语表、案例库和展示规则，辅助 SQL 生成。
🔎 反馈与分析中心
对不准确结果提交反馈，集中查看问题、建议和修正 SQL。
👤 用户与会话
保存并切换历史会话；管理员可创建、启停和维护普通用户。

3快速上手

  1. 登录系统
    使用管理员提供的用户名和密码登录。账户被禁用或超过有效期后将无法继续使用。
  2. 新建对话
    点击左侧 + 新对话 返回欢迎页。发送第一条问题后系统会自动保存会话，可在左侧列表切换或删除。
  3. 选择数据表
    在输入框上方选择与问题相关的数据表；不确定时可以不选，由系统结合已有数据判断。
  4. 输入分析问题
    尽量写明时间范围、股票代码、比较对象和期望展示方式，例如“展示 2025 年 1 月恒生指数走势，用折线图表示”。
  5. 查看并调整结果
    查看文字结论、SQL、数据表和图表。可修改图表类型、维度、指标、排序和 Top N，再继续追问。
  6. 复现或反馈
    展开计算链路查看口径和脚本；结果不符合预期时点击“结果不准确？”，随后在“分析中心”查看处理结果。
💡 提示：问题越具体，生成结果越稳定。涉及个股时建议使用五位股票代码，并明确自然日或报告期。

4导入自定义数据与样例文件

  1. 下载样例文件
    选择下方 CSV 日行情样例或 XLSX 季度财务样例。两份文件均为模拟数据，仅用于功能演示。
  2. 上传并预览
    进入 数据表管理，点击 上传 Excel，拖入文件或点击选择。支持 .csv、.xls、.xlsx，最大 300 MB；Excel 仅读取第一个工作表。
  3. 确认表与字段
    表名只能包含小写字母、数字和下划线。建议在默认名称后追加用户名或用途以保持唯一，并检查系统推断的 VARCHAR、BIGINT、DECIMAL、DATE 等类型。
  4. 建表并查询
    补充表注释和字段注释后确认建表。回到对话区选择新表，再输入下载卡片中的示例问题。

5管理员操作

  1. 打开用户管理
    管理员登录后点击顶部 用户管理；普通用户不会看到该入口，也无法调用相关接口。
  2. 创建普通用户
    填写用户名、初始密码、有效期和备注。密码至少 8 位，且同时包含字母、数字和特殊字符。
  3. 维护账户
    可启用或禁用账户、调整有效期并更新备注。有效期留空表示长期有效，选定日期当天结束前可用。
  4. 重置密码
    为普通用户设置符合策略的新密码。禁用、过期或重置密码后，该用户的已有会话会立即失效。
管理员账户由系统配置固定维护，不能在用户管理界面修改或删除。

6常见问题

Q1：查询结果不准确或没有数据怎么办？

检查时间范围、股票代码和所选数据表是否正确；尝试把复杂问题拆成两步。仍有问题时提交反馈，并在分析中心查看建议和修正 SQL。

Q2：为什么上传后的列类型不合适？

系统根据文件内容自动推断类型。请在确认建表前检查每一列，标识符应使用 VARCHAR，金额和比例可使用 DECIMAL，日期使用 DATE 或 DATETIME。

Q3：谁能看到我上传的数据表？

数据表列表按当前账户隔离。为避免物理表名冲突，请使用带用户名或用途后缀的唯一表名，不要直接复用他人的表名。

Q4：普通用户和管理员有什么区别？

普通用户可以使用对话、数据表、图表、知识库、分析中心和复现功能，唯独不能创建或维护其他用户。

User Guide / 使用说明

Hong Kong Market Data Explorer

AI-powered financial data querying, analysis, and visualization

1Overview

The system is designed for Hong Kong securities market analysis. Ask natural-language questions about the Hang Seng Index, stock trading, market capitalization, industry classifications, announcements, financial statements, and CCASS holdings. The system generates SQL, runs the query, and presents the result as text, tables, and charts.

Administrators and regular users share one sign-in page. Regular users can use every analysis feature; user management is available only to administrators.

2Core features

💬 Natural-language queries
Describe an analysis directly, receive streaming answers, and ask follow-up questions.
🗂️ Data source selection
Select system tables or your uploaded tables to focus the analysis.
📊 Tables and charts
Inspect paginated results and switch between line, bar, pie, and other charts.
🧮 Calculation lineage
Review metric definitions, SQL, and Python scripts, or download a reproduction package.
📁 Custom data tables
Upload CSV or Excel, preview columns, confirm types and descriptions, then create a table.
🧠 Knowledge base
Maintain business logic, glossaries, examples, and presentation rules for SQL generation.
🔎 Feedback and analysis
Report inaccurate results and review detected issues, suggestions, and corrected SQL.
👤 Users and conversations
Resume saved conversations; administrators can create and maintain regular users.

3Quick start

  1. Sign in
    Use the username and password supplied by your administrator. Disabled or expired accounts cannot continue using the system.
  2. Start a conversation
    Select + New Chat in the sidebar. A conversation is saved after you send its first question and can later be selected or deleted.
  3. Select data tables
    Choose relevant tables above the prompt. If you are unsure, leave the selection empty and let the system consider the available data.
  4. Ask a specific question
    Include the date range, stock code, comparison group, and desired presentation, such as “Show the Hang Seng Index trend for January 2025 as a line chart.”
  5. Review and refine
    Inspect the narrative, SQL, data table, and chart. Adjust the chart type, dimensions, metrics, sorting, or Top N, then ask a follow-up.
  6. Reproduce or report
    Expand the calculation lineage to inspect methodology and scripts. For an unexpected result, select “Inaccurate result?” and review the task in Analysis Center.
💡 Tip: Specific questions produce more stable results. For stocks, use five-digit codes and state whether dates refer to trading days or reporting periods.

4Import custom data and samples

  1. Download a sample file
    Choose the daily stock CSV or quarterly financial XLSX below. Both contain synthetic data for feature demonstrations only.
  2. Upload and preview
    Open Table Management, select Upload Excel, then drop or choose a file. The system accepts .csv, .xls, and .xlsx up to 300 MB; only the first Excel worksheet is read.
  3. Confirm the table and columns
    Table names may contain only lowercase letters, numbers, and underscores. Add your username or purpose to the default name to keep it unique, and verify inferred types such as VARCHAR, BIGINT, DECIMAL, and DATE.
  4. Create and query
    Add table and column descriptions, then create the table. Return to the conversation, select the new table, and try the prompt shown on its download card.

5Administrator tasks

  1. Open User Management
    After signing in as an administrator, select User Management in the header. Regular users neither see the entry nor have API access.
  2. Create a regular user
    Enter a username, initial password, expiry date, and optional note. Passwords require at least eight characters with a letter, number, and special character.
  3. Maintain an account
    Enable or disable the account, change its expiry, and update its note. A blank expiry means no expiry; a selected date remains valid through the end of that day.
  4. Reset a password
    Set a new policy-compliant password. Disabling, expiry, or password reset immediately invalidates the user’s existing sessions.
The administrator account is fixed by system configuration and cannot be edited or deleted in User Management.

6Frequently asked questions

Q1: What should I do when a query is inaccurate or returns no data?

Check the date range, stock code, and selected tables, then try splitting a complex request into smaller questions. If the issue persists, submit feedback and review the suggestion and corrected SQL in Analysis Center.

Q2: Why is an uploaded column assigned the wrong type?

The system infers types from file contents. Before creating the table, use VARCHAR for identifiers, DECIMAL for amounts or rates, and DATE or DATETIME for dates.

Q3: Who can see my uploaded tables?

The table list is scoped to the current account. To avoid physical table-name conflicts, use a unique name with your username or purpose and do not reuse another user’s table name.

Q4: What is the difference between a regular user and an administrator?

Regular users can use conversations, custom tables, charts, the knowledge base, Analysis Center, and reproduction features. Only user creation and maintenance are unavailable.
